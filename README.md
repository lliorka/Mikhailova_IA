# Mikhailova_IA
## Анализ продаж и прибыльности сети Superstore

## Цель / исследовательский вопрос
Какие категории и подкатегории товаров приносят наибольшую выручку, но при этом теряют прибыль
из-за скидок, и какие клиентские сегменты обеспечивают основную ценность бизнесу Superstore?

## Данные
Источник: kaggle.com/datasets/vivek468/superstore-dataset-final. Период: 2014-2017, 9994 строки, 21 поле. 

## Что сделано
Проверка качества данных, очистка (ETL), исследовательский анализ (EDA), ABC-анализ подкатегорий, XYZ-анализ подкатегорий, RFM-анализ клиентов, дашборд.

## Главный результат
Скидка свыше 20% делает позицию заказа в среднем убыточной; Tables и Bookcases убыточны, несмотря на
заметную выручку. Champions+Loyal (47.7% клиентов) дают 71% выручки.

## Основные выводы
1. Furniture (особенно Tables и Bookcases) даёт заметную выручку, но низкую/отрицательную прибыль
   из-за высоких скидок (>20%).
2. 8 из 17 подкатегорий формируют 80% выручки (ABC-группа A), но попадание в неё не гарантирует
   прибыльность.
3. Все подкатегории оказались нестабильны по спросу (XYZ = Z) — бизнес выражено сезонный.
4. 47.7% клиентов (Champions+Loyal) дают 71% выручки — приоритет для удержания.
